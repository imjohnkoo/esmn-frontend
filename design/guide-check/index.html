옛 가이드 사이트의 세 페이지(아이폰 간단 설치 확인 · 안드로이드 간단 설치 확인 · 통신사 변경/선택)를 설치 가이드(/guide/ios · /guide/android)와 같은 틀 · 같은 문체로 다시 그린 안입니다. 틀과 색은 가이드 골든을 그대로 링크했고, 폰 화면은 가이드 PNG 를 재사용하거나 같은 화면 템플릿으로 새로 그렸습니다. 원본 캡처는 쓰지 않았습니다. 주소 · 진입점 · 문구 차이는 아래 질문(Q1~Q9)과 «옛 글과 달라지는 곳» 표에 모았습니다.

재사용 가이드 PNG 그대로 새 화면 같은 템플릿으로 새로 굽기 추가 기존 가이드에 더하는 곳 사이트 머리 · 하단 탭 · 푸터는 단순화한 그림

아이폰 eSIM 설치 확인

현지에 도착해 여행용 eSIM을 켠 뒤, 아래 화면과 비교해 확인해 주세요.
설치 방법은 아이폰 설치 가이드에서 볼 수 있어요.

아이폰안드로이드
확인 1 셀룰러확인 2 회선확인 3 데이터확인 4 신호

화면의 빨간 테두리가 확인할 곳이에요.

확인 1

셀룰러 화면

설정 › 셀룰러를 열어 세 가지를 확인해요.

  • 셀룰러 데이터가 여행용 회선이에요.
  • SIMs의 메인과 여행용 회선이 모두 켬이에요.
  • 기본 음성 회선은 메인이에요.
새 화면 · ios-cellular · arrival · 강조 4

여행용 회선 이름은 폰이 붙여요. ‘여행’ · ‘보조’처럼 폰마다 달라도 괜찮아요.

한국에서는 여행용 회선이 ‘활성화 중…’으로 보이고 셀룰러 데이터는 메인이에요. 정상이에요.

다른 여행용 eSIM이 더 보이나요? 이번에 설치한 것 말고 다른 여행용 eSIM은 꺼 두세요. 지우지 않아도 돼요.

어느 회선인지 모르겠으면 지우지 말고 고객센터로 문의해 주세요. 한 번 지운 eSIM은 다시 설치할 수 없어요.

여행용 회선 설정

셀룰러 화면에서 여행용 회선을 눌러 세부 화면을 열어요.

  • 이 회선 켜기가 켜져 있어요.
  • 음성 및 데이터는 5G 자동이에요.
  • 데이터 로밍이 켜져 있어요. 가장 중요해요.
새 화면 · ios-line · 값 «5G 자동» 변형 · 강조 3
확인 3

셀룰러 데이터

설정 › 셀룰러 › 셀룰러 데이터를 열어요.

  • 여행용 회선에 체크 표시가 있어요.
  • 셀룰러 데이터 전환 허용은 꺼져 있어요.
재사용 · ios-celldata-travel.v1.png

한국 회선의 데이터 로밍은 꺼 두세요. 켜져 있으면 통신사 로밍 요금이 나올 수 있어요.

셀룰러 데이터 전환 허용도 꺼 두세요. 켜 두면 데이터가 한국 회선으로 넘어갈 수 있어요.

안드로이드 eSIM 설치 확인

현지에 도착해 모바일 데이터를 eSIM 1로 바꾼 뒤, 아래 화면과 비교해 확인해 주세요.
갤럭시 화면으로 안내해요. 설치 방법은 안드로이드 설치 가이드에서 볼 수 있어요.

확인 1

SIM 관리자

설정 › 연결 › SIM 관리자를 열어요.

  • 여행용 eSIM(eSIM 1)이 켜져 있어요.

  • 같은 화면 아래 데이터 전환은 꺼져 있어요.

다른 여행용 eSIM이 더 보이나요? 이번에 설치한 것 말고 다른 여행용 eSIM은 꺼 두세요. 지우지 않아도 돼요.

어느 회선인지 모르겠으면 지우지 말고 고객센터로 문의해 주세요. 한 번 지운 eSIM은 다시 설치할 수 없어요.

데이터 로밍

설정 › 연결 › 해외 로밍을 열어요.

  • 데이터 로밍 eSIM 1이 켜져 있어요.
  • 데이터 로밍 SIM 1은 꺼져 있어요.
재사용 · aos-roaming-esim.v1.png

SKT 폰은 메뉴가 달라요. 설정 › T로밍 › 로밍 상세 설정에서 데이터 로밍을 확인해 주세요.

데이터 로밍 SIM 1은 꺼 두세요. 켜져 있으면 통신사 로밍 요금이 나올 수 있어요.

데이터 전환도 꺼 두세요. 켜 두면 데이터가 국내 SIM으로 넘어갈 수 있어요.

Q4 현지에서 신호는 뜨는데 인터넷이 안 되나요?

새 회선의 데이터 로밍이 켜져 있는지, 셀룰러 데이터가 새 회선으로 되어 있는지 다시 확인해 주세요.
