# Lottie 자산

웹(`NLottie` · dotlottie-vue)과 앱(`NLottie` · lottie-react-native)이 같은 파일을 읽는다. 형식은 `.json`(`.lottie` 는 metro 설정이 필요해 나중).
자산을 더할 때 이 표에 출처 · 라이선스 · 정지 프레임(동작 줄이기 켬일 때 보여 줄 프레임)을 적는다.

| 파일 | 쓰임 | 출처 · 라이선스 | 길이 | 정지 프레임 |
| --- | --- | --- | --- | --- |
| `check-success.json` | 결과 일러스트(완료 체크) — 쇼케이스 예시 | 자체 제작(DS-MOTION 2026-11-12 · 손으로 쓴 JSON · 외부 자산 없음) · 리포 라이선스 | 60f @60fps = `motion.duration.celebrate` · 곡선 `motion.easing.out` · 색 `primary-500` | last-frame(원 + 체크 완성) |
